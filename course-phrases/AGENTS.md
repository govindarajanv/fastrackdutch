# Agent Instructions

This sub-app's working guide lives in **`CLAUDE.md`** in this same directory — read it before making any change to `index.html` here. It covers the `CHAPTERS` data model (`{dutch, pron, english}`), critical rules (never use subagents on `index.html`, read-before-edit, bump `VERSION` on every meaningful change), UI conventions, known issues, and version history.

This app is independent from the parent FastrackDutch app one level up (`../index.html`, `../CLAUDE.md`) — different data model, different semver, do not conflate the two.
